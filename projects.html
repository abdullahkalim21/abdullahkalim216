Projects

Ancestral Data & Lineage Tracking System - Database Systems

This project involves the design and implementation of a genealogical database system that empowers users to digitally construct, explore, and preserve their family history. The application allows users to create detailed profiles for individuals (both living and deceased), define complex family relationships (such as parent, child, and spouse), and record key life events like births, deaths, and migrations. A core feature of the system is its ability to track ancestral locations over generations, providing a dynamic way to visualize a family journey through time.

Tools: MySQL Workbench, SQL, HTML, CSS, JavaScript

Synapse UI/UX - Human Computer Interaction

The domain of Synapse is temporary cloud storage and data mobility. Its at the intersection of temporary file transfer services (like WeTransfer) and personal cloud storage (like Google Drive). It helps in the movement of digital assets between public (labs/libraries/work devices) and private environments (personal/home devices).

Tools: Figma

Loan Approval Prediction - Artificial Intelligence

This project aims to predict loan approval status using various machine learning algorithms. Financial institutions face challenges in evaluating loan applications efficiently and accurately. By leveraging historical loan data, this project compares multiple algorithms to identify the most effective model for predicting whether a loan should be approved or rejected.

Tools: Python, scikit-learn, Pandas, NumPy, Google Colab
